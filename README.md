# crossword-

## Учебный комикс по геометрии

В репозитории добавлен сайт-комикс **«Тетраэдр и параллелепипед»** на 16 слайдов.

- Отдельная иллюстрация на каждом слайде (встроенная SVG-графика).
- Описания граней, рёбер и вершин.
- Виды многогранников и формулы площади поверхности и объёма.
- Примеры из жизни, развёртки, задачи с решениями и проверка знаний.
- Переключение слайдов кнопками «Назад» / «Далее» и номерами без JavaScript.

### Просмотр

Откройте файл [index.html](./index.html). Если для репозитория включён GitHub Pages, сайт будет доступен по адресу Pages проекта.
